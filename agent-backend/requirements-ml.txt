#   pip install -r requirements.txt

#                  fallback used when it's absent).
#   soundfile      WAV decode used by both of the above.

# If `pip install -r requirements-ml.txt` fails with "No matching distribution
# for onnxruntime / ctranslate2", your Python is newer than their wheels. Either
# use a Python 3.12 venv for these extras, or just skip this file — the pipeline
# runs fine on the core set alone.
